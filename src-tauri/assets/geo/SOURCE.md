# Données de géocodage

`places.bin.z` est construit par `scripts/build-geonames.mjs` depuis les exports
[GeoNames](https://www.geonames.org/) `cities1000`, `admin1CodesASCII` et
`countryInfo`, téléchargés le 2026-10-21.
